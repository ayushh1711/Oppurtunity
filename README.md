
# Opportunity-X

### Student Opportunity and Campus Engagement Portal

Opportunity-X is a web-based platform designed for Graphic Era Hill University students to discover campus opportunities, explore clubs, register for events, and receive important announcements.

## Project Objectives

- Provide a common platform for students to explore university clubs and events.
- Help students discover opportunities based on their skills and interests.
- Allow students to maintain their profiles and manage their skills.
- Enable administrators to manage students, clubs, events, notices, and registrations.
- Keep students informed through announcements and notifications.

## Features

### Student Module
- Student registration and login
- Student profile management
- Skills and interests selection
- Club discovery and membership
- Event discovery and registration
- Notifications and announcements
- View club and event registrations
- Skill-based recommendations

### Admin Module
- Administrator registration and login
- Dashboard overview
- Student management
- Club management
- Event management
- Notice publishing
- Student registration overview

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage for prototype data storage

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.
3. Navigate through the available student and admin pages.

## Important Note

This project is currently being developed as a prototype. If browser Local Storage is used for data, information remains in that browser and is not automatically shared with other computers.

A production version should use a backend server, a database, secure authentication, and server-side authorization.
